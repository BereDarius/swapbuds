## ✨ Key Features

### 🛡️ Admin & Governance

- **Admin Dashboard**: Platform statistics, system health monitoring
- **User Management**: Search, view, ban/unban, role changes
- **Audit Logs**: Complete history of admin actions with filtering
- **Role-based Access**: ADMIN, MODERATOR, SUPPORT, USER roles

### 🚨 Safety & Moderation

- **Content Flagging**: Report inappropriate items, comments, users, trades
- **Moderation Dashboard**: Review and resolve flagged content
- **Flag Reasons**: SPAM, INAPPROPRIATE, SCAM, HARASSMENT, COPYRIGHT, FAKE, OTHER
- **Moderation Actions**: Approve, reject, remove with notes

### 🎫 User Support

- **Support Tickets**: Create and track support requests
- **Live Chat**: Real-time support conversations via WebSocket
- **Priority Levels**: LOW, MEDIUM, HIGH, URGENT
- **Status Tracking**: OPEN, IN_PROGRESS, RESOLVED, CLOSED
- **Typing Indicators**: Real-time typing feedback

### ⚖️ Dispute Resolution

- **Dispute System**: Report problems with trades
- **Dispute Reasons**: ITEM_NOT_RECEIVED, NOT_AS_DESCRIBED, DAMAGED, COUNTERFEIT
- **Evidence Upload**: Attach photos and descriptions
- **Resolution Process**: PENDING, INVESTIGATING, RESOLVED, REJECTED

### ✅ Trust & Safety

- **ID Verification**: Document upload for user verification
- **Document Types**: ID_CARD, PASSPORT, DRIVERS_LICENSE
- **Verification Status**: PENDING, APPROVED, REJECTED with review times
- **Verified Badge**: Display verified status throughout platform

## 🚀 Getting Started

### Prerequisites

- Node.js 18+
- Yarn package manager
- PostgreSQL 14+
- Docker & Docker Compose (for local development)

### Installation

```bash
# Pull latest code
git pull origin main

# Install dependencies for both frontend and backend
yarn install:all

# Start Docker services (PostgreSQL, Redis)
docker-compose up -d

# Run database migrations (backend)
cd swapbuds-backend
yarn prisma migrate deploy
yarn prisma generate

# Start both applications
cd ..
yarn dev
```

### Environment Variables

No new environment variables required for this release. Ensure your existing `.env` files are properly configured.
