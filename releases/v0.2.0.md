# Release v0.2.0 - Items & Authentication

**Release Date:** November 2024
**Version:** 0.2.0
**Type:** Feature Release

## 🎯 What's New

SwapBuds v0.2.0 brings the core marketplace functionality - you can now create accounts, list items, and browse the catalog. This release establishes the foundation for trading between users.

## ✨ Key Features

### For Users

- **Create Your Account**: Sign up with email and password to get started
- **List Your Items**: Add items you want to trade with detailed information
- **Browse Items**: View all available items in the marketplace with pagination
- **Categorize Items**: Choose from 8 categories (Electronics, Clothing, Books, Toys, Sports, Collectibles, Home, Other)
- **Item Condition**: Set condition levels (New, Like New, Good, Fair, Poor)
- **Secure Platform**: Your data is protected with modern authentication

### For Developers

- **API Documentation**: Interactive Swagger docs for easy integration
- **Error Monitoring**: Production-ready error tracking
- **Developer Tools**: Improved logging and debugging capabilities

## 🚀 Getting Started

### Quick Start

1. Visit the platform and create an account
2. Log in with your credentials
3. Start adding items you want to trade
4. Browse items from other users

### For Self-Hosting

```bash
# Clone the repository
git clone --recursive https://github.com/BereDarius/swapbuds.git
cd swapbuds

# Start infrastructure
docker-compose up -d

# Start backend
cd swapbuds-backend
yarn install && yarn dev

# Start frontend (in new terminal)
cd swapbuds-frontend
yarn install && yarn dev
```

Visit `http://localhost:3000` to access the application.
