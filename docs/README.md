## 📝 Contributing to Documentation

When adding or updating documentation:

1. **Place it in the right category** - Use the structure above
2. **Update this README** - Add links to new documents
3. **Use clear headings** - Make documents easy to scan
4. **Include examples** - Show, don't just tell
5. **Keep it current** - Update docs when features change
6. **Link related docs** - Help readers find context
